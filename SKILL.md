# Gemini (Antigravity) lecture transcription

Use when transcribing long lecture/audio files (e.g. Persian university lectures). Uses Gemini via Oh My Pi Antigravity accounts rather than local Whisper.

## Pipeline (run with `py -3.12`; all scripts stdlib-only + `ffmpeg`)
One workdir per lecture: `lectures/<audio-basename>/`. Any `ffmpeg`-readable input works (`.mp3`, `.m4a` mono/stereo, etc.).

1. `py -3.12 segment.py <audio> lectures/<name>`: decodes audio, cuts 60–120 s segments at the quietest 400 ms window, writes `seg/*.flac` + `segments.json` (`{audio, duration, segments:[{i,start,end,file,speech}]}`). Check the printout: cuts above 25% of speech level need a join check after the run (end of seg `k` vs start of seg `k+1` must continue the sentence). If the folder also holds `<name>_1`/`<name>_2` part files plus an Audition `.sesx` project folder, `<name>` is the merged recording: transcribe the named file and confirm `ffprobe` durations of parts sum to the merged file. Check the splice (offset = duration of part 1) with `ffmpeg -ss <t-10> -t 25 ... silencedetect` / per-second RMS: continuous speech there = no gap; inspect the segment that contains it.
2. Write `lectures/<name>/context.json` (see `context.example.json`): `{"title": <Persian transcript title>, "course": "<Course>, <program>, <which session>", "terms_rule": "Spell names, books and technical terms in their standard Persian form, e.g. <course-specific Persian name list>. <script rule for Arabic/foreign terms>"}`. Copy an existing lecture of the same course (updating title and session) so the terminology list stays consistent.
3. Pilot: `py -3.12 gem_pipeline.py ag lectures/<name> --only 0,1,<middle> --workers 3`, then `py -3.12 review.py lectures/<name> show 0,1,<middle>`; read the texts (speaker labels, timestamps, no omissions). Run the pilot in the foreground and wait for it.
4. Full run (background) plus cross-check can run at the same time (separate quotas). Cross-check uses the Gemini API key free tier: 25 req/day per model, resets daily, stops itself at quota. Sample every 5th segment (or every 6th, leaving spare requests for date/admin/tie-break segments): `py -3.12 gem_pipeline.py ag lectures/<name> --workers 3` and `py -3.12 gem_pipeline.py pass1 lectures/<name> --workers 3 --only 0,5,10,...`.
5. Full run takes ~15–60 min per 2.5–3 h lecture depending on server load (resumable). Check progress with `wc -l ag_*.jsonl` rather than re-waiting blindly; the log only prints a segment when it finishes, and a single segment can take several minutes across a token refresh. If the PC sleeps or the network drops mid-run, in-flight segments end as `FAILED a,b,c`; re-run with `--only a,b,c` (the refresher renews expired tokens on start).
6. `py -3.12 assemble.py lectures/<name> NUL --qa-only` (or `/dev/null` on Unix) -> fix flags (re-run flagged segments by deleting their lines from `ag_*.jsonl` and passing `--only`). `py -3.12 review.py lectures/<name> compare` (`ag` vs `pass1`: similarity, word counts) and `... pair <ids>` for the lowest-similarity segments. `pass1` often drops student turns, Arabic readings, or slowly dictated examples (sometimes returning empty), so read both before acting. Common benign flags: "4-gram repeated" = lecturer repeating an example sentence or rhetorical phrase; "low density" = break announcement/silence. Read the segment before re-running.
7. Dates, numbers, times, rooms: models can mishear spoken numbers or clock times by a digit or hour. `py -3.12 review.py lectures/<name> scan` lists date/admin lines. Run `pass1 --only <seg>` on any segment with dates/times/administrative info (the first and last segments often have announcements). If the two disagree, tie-break by asking 3–4 Antigravity models (`gemini-3.8-flash-high/medium/low`, `gemini-3-flash`) the same narrow question about that segment's audio (asking for exact quoted Persian words plus digits at `temperature: 0` via `gem_pipeline.ag_call`). Fix `ag_*.jsonl` text only when the majority disagrees with it (adding a `manual_fix` note) so reassembly keeps the fix. Models share a family, so note that when reporting.
8. `py -3.12 assemble.py lectures/<name> "<audio dir>/<basename>_transcript.md"` (run to completion before reading the file); inspect the beginning and end; check timestamps are monotonic (`assemble.py` flags and drops stamps that run backwards `> 2 s` inside a segment, never guessing), last stamp approximates audio duration, no Persian-digit stamps remain, and odd Latin-script tokens make sense in context.
9. Report: provide the full transcript path. Count markers on the body only (`tail -n +9`): the header legend lists `[نامفهوم]`/`[همهمه]`, so whole-file greps overcount by one. Count speaker turns as labelled lines `^\*\*(\[[^]]+\] )?(استاد|دانشجو)` — not only stamped ones (the model stamps ~60–70% of turns). State completion status (`finish=STOP`), any QA flags/findings, and how the recording begins/ends (e.g. mid-sentence or mid-conversation).

## Engine facts
- Primary: `gemini-3.8-flash-high` via Antigravity: verbatim colloquial Persian, speaker labels `استاد`/`دانشجو` (`دانشجو N` in multi-student exchanges), `[mm:ss]` stamps (sometimes Persian digits `[۰۰:۳۲]`; `assemble.py` normalizes them), punctuation, English/foreign terms in Latin script. Rotates across active Antigravity accounts.
- `gemini-3.5-transcribe` (API key): no labels/timestamps, drops student dialogue and boundary fragments; cross-check only, useful for spoken numbers.
- Antigravity call: `POST https://daily-cloudcode-pa.googleapis.com/v1internal:streamGenerateContent?alt=sse`, Bearer token from `~/.omp/agent/agent.db` (`auth_credentials`, provider `google-antigravity`, `disabled_cause IS NULL`), `User-Agent: antigravity/hub/2.19.1 (aidev_client; os_type=darwin; arch=arm64; cl=963137146)`, body `{project, model, request:{contents, generationConfig}, userAgent:'antigravity', requestId:'agent-<uuid>'}`.
- Tokens last ~1 h and OMP refreshes only on use near expiry; the pipeline's refresher runs `omp -p --model google-antigravity/gemini-3.8-flash "Reply with the single word OK"` when `< 4 min` remain.
- QA heuristic: words per minute of detected speech; ~150–230 is normal for lecturers; `< 60%` of the lecture median indicates a likely omission.
- Long English quotations or Arabic passages read aloud may be rendered in their published wording rather than exactly as read; flag for spot-checking.
- Never print API keys or OAuth tokens.
